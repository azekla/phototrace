# PhotoTrace — запуск на Windows

PhotoTrace проверяет изображение моделью и показывает доступные метаданные файла. Работает локально: сайт открывается в браузере на вашем компьютере.

## Первый запуск

1. Нажмите на GitHub **Code → Download ZIP** и распакуйте **весь архив** в обычную папку, например `C:\PhotoTrace`. Не запускайте файлы прямо внутри ZIP. Если проект уже скачан, просто откройте папку с `SETUP.cmd`.
2. Установите [Python 3.12 x64 с официального сайта](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe). При установке включите пункт **Add python.exe to PATH**. Если Python 3.12 уже установлен, этот шаг пропустите. После установки откройте папку проекта заново и запустите `SETUP.cmd`.
3. При подключённом интернете дважды щёлкните `SETUP.cmd`. Скрипт создаст окружение, установит библиотеки и подготовит локальную базу. Нейросетевая модель уже включена в проект и отдельно не скачивается. Дождитесь сообщения `Setup completed. Run START.cmd next.`
4. Дважды щёлкните `START.cmd` и откройте в браузере адрес **http://127.0.0.1:8000/**. Оставьте окно запуска открытым на время работы. Для остановки нажмите в нём **Ctrl+C**.

При следующих запусках нужен только `START.cmd`. Для обработки изображений интернет не требуется. Если адрес не открывается, проверьте, не занят ли порт 8000 другой программой, и посмотрите сообщение в окне запуска.

## Возможности и ограничения

- Загрузка изображения, оценка модели, просмотр EXIF и других доступных метаданных, история проверок и экспорт результата.
- Изображения и база проверок сохраняются только в папке `var` на вашем компьютере. Не передавайте её вместе с программой, если в ней есть личные фотографии.
- Оценка модели может ошибаться. Она не является доказательством подлинности или подделки. Метаданные тоже можно изменить или удалить.

Используется модель [Community Forensics ViT-Small v13](https://huggingface.co/angelhd25/ull-ai-image-detector). Сведения об авторах, ограничениях и условиях использования приведены в карточке модели. Программные библиотеки устанавливаются из `requirements.txt`.
